# Фокус дня

Интерактивный дизайн-кейс и прототип дневной статистики здоровья на Vite и TypeScript.

## Возможности

- Гипотеза, сравнение «до/после» и хронология решений с промежуточными экранами.
- Три фокуса дня с анимированным заполнением иллюстраций.
- Переключение дат, дневные показатели и отметки выполненных целей.
- Полноэкранное исследование прототипа: макап на компьютере и интерфейс без рамки на телефоне.
- Поддержка уменьшения движения (`prefers-reduced-motion`).

На узких экранах макеты закреплены в верхней части, пояснения прокручиваются отдельно под ними. Этапы переключаются стрелками; кнопки остаются на месте. После девятого шага открывается хронология с возвратом к разбору. На компьютере сохранён сценарий с прокруткой страницы.

Прототип использует демонстрационные данные. «Прогресс» описан в кейсе как предложенная фича; отдельный экран пока не реализован.

## Локальный запуск

Нужен Node.js 22.12+.

```sh
npm ci
npm run dev
```

## Проверки и сборка

```sh
npm run check
npm test
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Проверки охватывают TypeScript, наличие ассетов, геометрию кейса, переходы и жесты.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует сайт только по ручному запуску `workflow_dispatch`. В настройках Pages источник — **GitHub Actions**. Относительные пути ассетов позволяют размещать сборку под путём репозитория.
